# API documentation

The core of `flowprog` is the {py:class}`flowprog.ModelBuilder` class, described in {doc}`api-model`.

Environmental accounting -- elementary exchanges, boundary processes, reporting, and allocation -- is described in {doc}`api-exchanges`.

On top of this, an additional layer allows for loading model structures from system definitions -- either directly, or from RDF data exported from them -- described in {doc}`api-io`.
